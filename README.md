# Өлшем

Платформа для методистов: показывает по результатам СОР, какие темы программы усваиваются хуже всего и почему, какой учебник работает лучше при равном уровне учеников и как перераспределить учебные часы.

Кейс 1 «Data-Driven Curriculum», EdTech Hackathon by Zhambyl Hub, 2026.

## Что умеет

- **Сложные темы.** Средний балл, доля не справившихся, разброс между школами по каждой теме.
- **Корень проблемы.** Находит более раннюю тему, провал которой сильнее всего повышает шанс провалить текущую.
- **Честное сравнение учебников.** Сильные школы чаще выбирают определённые учебники, поэтому простые средние обманывают. Модель убирает вклад входного уровня учеников и количества часов. Неопределённость считается бутстрепом по школам.
- **Рекомендации по часам.** Оценивает, сколько даёт каждый лишний час на тему, и переносит часы туда, где прирост больше, в пределах заданных ограничений.
- **Заключение для методсовета** с сохранением в PDF.
- Интерфейс на русском и казахском.

Нейросетей внутри нет: каждый вывод можно проверить и объяснить. Расчёт идёт в браузере, поэтому данные учеников не уходят на сервер.

## Запуск

```bash
npm start      # http://localhost:3000
npm test
```

Зависимостей нет, нужен Node 20+.

## Свои данные

CSV, одна строка — один ученик по одной теме. Колонки: `district`, `school`, `class`, `textbook`, `student`, `baseline`, `topic`, `hours`, `score` (русские и казахские заголовки тоже понимаются). Образец скачивается на вкладке «Данные».

Демо-данные синтетические: 24 школы Жамбылской области, алгебра 7 класса, 9 тем, 3 учебника.
