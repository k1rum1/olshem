## Зачем нужны подпрограммы
**Подпрограмма** — именованный фрагмент программы, который можно вызывать много раз. Она убирает повторы кода, упрощает поиск ошибок и позволяет делить задачу на части.

Подпрограммы бывают двух видов:
- **процедура** выполняет действия (например, печатает), но ничего не возвращает;
- **функция** вычисляет и **возвращает** значение через `return`.

В Python оба вида объявляют словом `def`. Процедура — это функция без `return`: она возвращает `None`.

```python
def greet(name):          # процедура: только печатает
    print("Сәлем,", name)

def square(x):            # функция: возвращает результат
    return x * x

greet("Айгерим")
y = square(5) + 1         # y = 26
```

## Параметры и аргументы
- **Параметры (формальные)** — имена в заголовке функции: `def area(a, b):`.
- **Аргументы (фактические)** — значения при вызове: `area(3, 4)`.

```python
def area(a, b=1):         # b = 1 — значение по умолчанию
    return a * b

area(3, 4)                # 12, позиционные аргументы
area(5)                   # 5, b взят по умолчанию
area(b=2, a=7)            # 14, именованные аргументы
```

Функция может вернуть несколько значений сразу: `return s, p` — и принять их: `s, p = calc(3, 4)`.

> Числа, строки и кортежи в Python неизменяемые: если поменять параметр внутри функции, переменная снаружи не изменится. Список изменяемый: `lst.append(...)` внутри функции изменит исходный список.

## Локальные и глобальные переменные
- **Локальная** переменная создана внутри функции и видна только там.
- **Глобальная** создана вне функций и видна везде. Чтобы **изменить** её внутри функции, нужно объявить `global`.

```python
count = 0                 # глобальная

def add():
    global count
    count += 1            # без global здесь будет ошибка
    temp = 10             # локальная, снаружи не видна

add()
print(count)              # 1
```

Хорошая практика — передавать данные через параметры и `return`, а не через глобальные переменные.

**Встроенные функции** Python уже готовы к использованию: `len`, `abs`, `max`, `min`, `sum`, `round`, `int`, `str`, `input`, `print`. Дополнительные функции подключают из **модулей**: `import math` → `math.sqrt(16)`.

**Анонимная функция** `lambda` записывается в одну строку: `sq = lambda x: x * x`. Её часто используют как ключ сортировки.

## Рекурсия
**Рекурсия** — вызов функцией самой себя. У рекурсивной функции обязательно есть две части:
1. **Базовый случай** — условие, при котором функция возвращает ответ без нового вызова. Без него вызовы будут бесконечными, и программа завершится ошибкой `RecursionError`.
2. **Рекурсивный шаг** — вызов себя для более простой задачи.

**Факториал**: n! = n · (n − 1)!, 0! = 1.

```python
def fact(n):
    if n <= 1:            # базовый случай
        return 1
    return n * fact(n - 1)  # рекурсивный шаг

fact(4)  # 4 · 3 · 2 · 1 = 24
```

Как это работает: `fact(4)` ждёт `fact(3)`, тот ждёт `fact(2)`, тот — `fact(1)`. Незавершённые вызовы хранятся в **стеке вызовов**. Когда `fact(1)` вернул 1, стек «разматывается»: 2·1 = 2, 3·2 = 6, 4·6 = 24.

**Числа Фибоначчи**: F(1) = F(2) = 1, F(n) = F(n−1) + F(n−2).

```python
def fib(n):
    if n <= 2:
        return 1
    return fib(n - 1) + fib(n - 2)
```

> Такая функция пересчитывает одни и те же значения много раз и при n = 40 работает очень долго. Цикл решает задачу быстрее. Рекурсия удобна там, где задача естественно делится на похожие подзадачи: обход дерева, сортировка слиянием, перебор вариантов.

**НОД по алгоритму Евклида**: НОД(a, b) = НОД(b, a mod b), НОД(a, 0) = a.

```python
def gcd(a, b):
    if b == 0:
        return a
    return gcd(b, a % b)

gcd(48, 18)  # 6
```

**Трассировка в задачах ЕНТ.** Часто спрашивают, что выведет рекурсивная функция. Выписывайте вызовы столбиком и значения на обратном пути:

```python
def f(n):
    if n > 0:
        print(n, end=' ')
        f(n - 2)
f(7)   # 7 5 3 1
```

- Параметр :: имя переменной в заголовке функции

- Локальная переменная :: переменная, видимая только внутри функции
- Глобальная переменная :: переменная, созданная вне функций
- Рекурсия :: вызов функцией самой себя
- Базовый случай :: условие, при котором рекурсия прекращается
- Стек вызовов :: память, где хранятся незавершённые вызовы функций
