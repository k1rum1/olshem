## Сайт и веб-страница
**Веб-страница** — документ, который браузер показывает пользователю. **Сайт** — набор связанных страниц с общим адресом (доменом).

- **Статический** сайт — страницы заранее написаны и одинаковы для всех посетителей.
- **Динамический** сайт — страницы собираются «на лету», часто из базы данных: интернет-магазин, электронный дневник.

**Этапы создания сайта:** цель и аудитория → структура (карта страниц) → дизайн → вёрстка (HTML и CSS) → наполнение → проверка → размещение на хостинге.

Создать сайт можно в **конструкторе** (Tilda, Wix — без кода) или написать код вручную в редакторе: Блокнот, Notepad++, Visual Studio Code.

## Теги и структура документа
**HTML** (HyperText Markup Language) — язык разметки: он описывает, **что** находится на странице (заголовок, абзац, таблица), а не как это выглядит. Оформление задаёт CSS.

**Тег** — команда в угловых скобках. Большинство тегов **парные**: открывающий `<p>` и закрывающий `</p>`. **Одиночные** теги не закрываются: `<br>`, `<img>`, `<hr>`, `<meta>`.

**Атрибут** уточняет тег: `<img src="logo.png" alt="Логотип" width="200">`. Здесь `src`, `alt`, `width` — атрибуты, в кавычках — их значения.

```html
<!DOCTYPE html>
<html lang="ru">
<head>
  <meta charset="utf-8">
  <title>Моя школа</title>
</head>
<body>
  <h1>Школа-гимназия №1</h1>
  <p>Добро пожаловать!</p>
</body>
</html>
```

- `<!DOCTYPE html>` — сообщает браузеру, что это HTML5;
- `<head>` — служебная часть: кодировка, заголовок вкладки `<title>`, подключение стилей;
- `<body>` — всё, что видно на странице.

Файл сохраняют с расширением `.html`, главную страницу сайта обычно называют `index.html`.

## Текст
| Тег | Назначение |
|---|---|
| `<h1>` … `<h6>` | заголовки шести уровней, `h1` — самый крупный |
| `<p>` | абзац |
| `<br>` | перенос строки |
| `<hr>` | горизонтальная линия |
| `<b>`, `<strong>` | жирный (`strong` — ещё и «важно» по смыслу) |
| `<i>`, `<em>` | курсив (`em` — смысловое выделение) |
| `<u>` | подчёркивание |
| `<sub>`, `<sup>` | нижний и верхний индекс: H`<sub>`2`</sub>`O, x`<sup>`2`</sup>` |

Атрибут `align` (`left`, `center`, `right`) выравнивает текст, а тег `<font color="red" size="5" face="Arial">` меняет шрифт. Оба способа **устарели**: в HTML5 оформление задают через CSS.

**Цвет** задают названием (`red`) или шестнадцатеричным кодом `#RRGGBB`: каждая пара — интенсивность красного, зелёного и синего от `00` до `FF`. `#FF0000` — красный, `#000000` — чёрный, `#FFFFFF` — белый.

## Списки
```html
<ul>                  <!-- маркированный -->
  <li>Python</li>
  <li>HTML</li>
</ul>
<ol type="1" start="3">  <!-- нумерованный, с 3 -->
  <li>Анализ</li>
  <li>Дизайн</li>
</ol>
```

У `<ol>` атрибут `type` задаёт вид нумерации: `1`, `A`, `a`, `I`, `i`. Есть ещё **список определений** `<dl>`: термин `<dt>` и определение `<dd>`.

## Таблицы
```html
<table border="1">
  <tr>
    <th>Предмет</th><th>Балл</th>
  </tr>
  <tr>
    <td>Информатика</td><td>95</td>
  </tr>
  <tr>
    <td colspan="2">Итого: 1 предмет</td>
  </tr>
</table>
```

- `<table>` — таблица, `<tr>` — строка, `<td>` — ячейка, `<th>` — ячейка-заголовок (жирная, по центру);
- `colspan="2"` объединяет две ячейки по горизонтали, `rowspan="2"` — по вертикали;
- `border`, `cellpadding`, `cellspacing`, `width` — устаревшие атрибуты оформления, сейчас их задают в CSS.

## Изображения и ссылки
**Изображение:** `<img src="photo.jpg" alt="Описание" width="300">`. Атрибут `alt` — текст, если картинка не загрузилась; его читают программы для незрячих. Форматы для сайтов: JPEG — фотографии, PNG — картинки с прозрачностью, GIF — простая анимация, SVG — векторная графика.

**Гиперссылка** — тег `<a>` с атрибутом `href`:

```html
<a href="about.html">О школе</a>                     <!-- на страницу сайта -->
<a href="https://edu.gov.kz" target="_blank">МОН РК</a>  <!-- в новой вкладке -->
<a href="mailto:info@school.kz">Написать</a>         <!-- письмо -->
<a href="#contacts">Контакты</a>                     <!-- якорь на этой странице -->
<h2 id="contacts">Контакты</h2>
```

Ссылкой может быть и картинка: `<a href="index.html"><img src="logo.png" alt="На главную"></a>`.

**Пути к файлам** бывают **абсолютными** (`https://site.kz/img/a.png`) и **относительными** (`img/a.png` — от текущей страницы, `../a.png` — на папку выше).

## Структура страницы в HTML5
Для разметки блоков используют универсальные теги `<div>` (блок) и `<span>` (часть строки), а также **семантические** теги, которые сами говорят о смысле блока: `<header>` — шапка, `<nav>` — меню, `<main>` — основное содержимое, `<section>` — раздел, `<article>` — статья, `<aside>` — боковая колонка, `<footer>` — подвал.

Правильность кода проверяют валидатором W3C: validator.w3.org.

@terms
- HTML :: язык гипертекстовой разметки веб-страниц
- Тег :: команда разметки в угловых скобках
- Атрибут :: дополнительный параметр тега: имя="значение"
- Парный тег :: тег, у которого есть закрывающая часть
- Гиперссылка :: элемент, переводящий на другой ресурс, тег a с атрибутом href
- Якорь :: ссылка на место внутри страницы через #id
- Относительный путь :: путь к файлу от текущей страницы
