## Интернет вещей
**Интернет вещей (IoT, Internet of Things)** — сеть физических предметов со встроенными датчиками, процессорами и связью, которые обмениваются данными друг с другом и с облаком без участия человека.

**Из чего состоит система IoT:**
1. **Датчики (сенсоры)** измеряют мир: температуру, влажность, движение, свет, дым, расход воды.
2. **Контроллер** (микроконтроллер Arduino, ESP32, мини-компьютер Raspberry Pi) обрабатывает данные.
3. **Связь:** Wi-Fi, Bluetooth, Zigbee (экономичная сеть умного дома), LoRa и NB-IoT (большие расстояния при малом энергопотреблении), мобильная связь.
4. **Облачная платформа** хранит и анализирует данные, связывает устройства.
5. **Исполнительные устройства (актуаторы)** действуют: реле, моторы, клапаны, замки, лампы.
6. **Приложение** — интерфейс для человека: смотреть показания и управлять.

**Цикл работы:** датчик измерил → данные ушли в облако → правило или алгоритм приняли решение → исполнительное устройство выполнило действие → человек получил уведомление.

**Где применяют:** умный дом, умный город (освещение, парковки, светофоры, учёт воды и тепла), сельское хозяйство (датчики влажности почвы и автоматический полив), промышленность (**IIoT** — контроль станков, предсказание поломок), медицина (фитнес-браслеты, мониторинг пациентов), логистика (отслеживание грузов).

**Риски:** уязвимые устройства с заводскими паролями взламывают и объединяют в ботнеты для DDoS-атак, утекают личные данные, а без интернета часть функций перестаёт работать. Защита: сменить пароль по умолчанию, обновлять прошивку, вынести устройства в отдельную сеть Wi-Fi.

## Умный дом
**Умный дом** — жилище, где устройства связаны в систему и работают по сценариям, экономя ресурсы и повышая безопасность и комфорт.

| Подсистема | Датчики | Действия |
|---|---|---|
| Освещение | движения, освещённости | включить свет при входе, приглушить ночью |
| Климат | температуры, влажности, CO₂ | включить отопление, кондиционер, проветривание |
| Безопасность | открытия двери, движения, камеры | уведомление на телефон, сирена |
| Защита от аварий | протечки, дыма, газа | перекрыть воду или газ, вызвать помощь |
| Энергосбережение | счётчики, розетки с измерением | выключить приборы в режиме ожидания |

**Сценарий** — правило «если…, то…»: «если после 22:00 датчик движения в коридоре сработал, включить ночник на 30% на 2 минуты». Управлять можно из приложения, голосом через помощника или автоматически.

**Этапы проекта умного дома:** определить задачи → составить план помещений и расставить датчики → выбрать протокол и центр управления (хаб) → подобрать устройства и посчитать бюджет → описать сценарии → смоделировать или собрать прототип (Arduino, Tinkercad Circuits) → протестировать.

## Мобильные приложения
**Мобильное приложение** — программа для смартфона или планшета. Его можно написать на языке программирования (Kotlin и Java для Android, Swift для iOS) или собрать в **визуальном конструкторе** без кода: MIT App Inventor, Thunkable, Kodular.

**Требования к интерфейсу мобильного приложения:**
- крупные элементы, удобные для пальца (не меньше 7–10 мм), основные кнопки — в зоне большого пальца;
- одна главная задача на экран, минимум текста;
- понятные значки и подписи, единый стиль на всех экранах;
- читаемый шрифт и достаточный контраст;
- обратная связь: приложение показывает, что действие выполнено;
- работа в вертикальной и горизонтальной ориентации, на разных размерах экранов.

## Создание приложения в App Inventor
В App Inventor две части:
1. **Дизайнер (Designer)** — собираем экран из **компонентов**: видимые — `Button` (кнопка), `Label` (надпись), `TextBox` (поле ввода), `Image`, `ListView`; невидимые — `Sound`, `Clock` (таймер), `TinyDB` (хранение данных), датчики `AccelerometerSensor`, `LocationSensor`.
2. **Блоки (Blocks)** — программируем поведение, соединяя блоки как пазл. Логика строится на **событиях**: «когда `Button1.Click` → установить `Label1.Text` в …».

**Пример — счётчик воды за день:** кнопка «+1 стакан» увеличивает переменную `count` и показывает её в `Label`, а `TinyDB` сохраняет значение, чтобы оно не пропало после закрытия приложения.

**Установка:** «Build → Android App (.apk)». Готовый файл **APK** можно скачать по **QR-коду** или передать на телефон и установить, разрешив установку из неизвестных источников. Для тестирования во время разработки используют приложение-компаньон **MIT AI2 Companion**. Для широкой публикации приложение загружают в магазин **Google Play** (Android) или **App Store** (iOS).

@terms
- Интернет вещей :: сеть устройств с датчиками и связью, обменивающихся данными без участия человека
- Датчик :: устройство, измеряющее физическую величину
- Исполнительное устройство :: устройство, выполняющее действие по команде: реле, мотор, клапан
- Микроконтроллер :: маленький компьютер на одной микросхеме для управления устройствами
- Zigbee :: экономичный беспроводной протокол для умного дома
- Умный дом :: жилище с устройствами, работающими по сценариям
- Сценарий :: правило автоматизации «если…, то…»
- Визуальный конструктор :: среда создания приложений из готовых блоков
- APK :: установочный файл Android-приложения
