## Что такое искусственный интеллект
**Искусственный интеллект (ИИ)** — область информатики, которая создаёт системы, решающие задачи, обычно требующие человеческого мышления: распознавать изображения и речь, понимать текст, принимать решения, учиться на опыте.

**Вехи истории:**
- **1950** — Алан Тьюринг предложил **тест Тьюринга**: машина «мыслит», если в переписке её нельзя отличить от человека;
- **1956** — Дартмутский семинар, Джон Маккарти вводит термин «искусственный интеллект»;
- 1970–80-е — **экспертные системы**: базы правил «если…, то…» от специалистов (диагностика болезней);
- 2010-е — **глубокое обучение** на больших данных: распознавание лиц, переводчики, голосовые помощники;
- 2020-е — **генеративный ИИ**: языковые модели и чат-боты, генерация изображений.

**Слабый (узкий) ИИ** решает одну задачу (шахматы, распознавание номеров машин). Все существующие сегодня системы — слабый ИИ. **Сильный (общий) ИИ**, равный человеку во всех задачах, пока не создан.

## Где применяют ИИ
| Сфера | Пример |
|---|---|
| Медицина | поиск опухолей на снимках, подбор лечения |
| Транспорт | беспилотные автомобили, навигаторы с прогнозом пробок |
| Финансы | выявление мошеннических операций, кредитный скоринг |
| Сельское хозяйство | анализ снимков полей с дронов, прогноз урожая |
| Образование | подбор заданий под уровень ученика, анализ результатов тестов |
| Город и безопасность | распознавание лиц и номеров, умное освещение |
| Связь с людьми | чат-боты, переводчики, голосовые помощники |

## Машинное обучение
**Машинное обучение (ML)** — раздел ИИ, в котором программа не получает готовых правил, а **сама находит закономерности в данных**. Данные для обучения называют **обучающей выборкой**, а для проверки качества используют отдельную **тестовую выборку**.

| Вид обучения | Как учится | Задачи | Пример |
|---|---|---|---|
| С учителем | на примерах с правильными ответами (метками) | **классификация** (выбрать класс), **регрессия** (предсказать число) | «спам / не спам», прогноз цены квартиры |
| Без учителя | ответов нет, ищет структуру сама | **кластеризация** (разбить на похожие группы) | сегменты покупателей |
| С подкреплением | пробует действия и получает награду или штраф | стратегия, управление | игра в го, робот учится ходить |

**Переобучение** — модель «зазубрила» обучающую выборку, включая случайный шум, и плохо работает на новых данных. Поэтому качество всегда проверяют на данных, которых модель не видела.

## Нейрон и нейронная сеть
**Искусственный нейрон (перцептрон)** — упрощённая модель нервной клетки:
1. Получает входы x₁, x₂, …, xₙ.
2. Умножает каждый на свой **вес** wᵢ — насколько этот вход важен.
3. Складывает и добавляет **смещение** b: S = w₁x₁ + w₂x₂ + … + wₙxₙ + b.
4. Применяет **функцию активации**, например пороговую: выход 1, если S ≥ 0, иначе 0.

**Пример.** Решение «идти на прогулку»: x₁ — хорошая погода (1/0), x₂ — сделаны уроки (1/0). Веса w₁ = 0,6, w₂ = 0,6, порог 1 (то есть b = −1). Если оба условия выполнены: S = 0,6 + 0,6 − 1 = 0,2 ≥ 0 → идти. Если выполнено одно: S = −0,4 → не идти. Такой нейрон реализует логическую операцию **И**.

**Нейронная сеть** — нейроны, соединённые в **слои**:
- **входной** слой получает данные (пиксели картинки, признаки);
- **скрытые** слои находят всё более сложные признаки;
- **выходной** слой выдаёт ответ (вероятность каждого класса).

Сеть с большим числом скрытых слоёв называют **глубокой**, а её обучение — **глубоким обучением**.

**Как сеть обучается:** сначала веса случайные. Сеть делает прогноз, считается **ошибка** (насколько ответ отличается от правильного), и веса немного сдвигаются так, чтобы ошибка уменьшилась. Метод **обратного распространения ошибки** передаёт поправки от выходного слоя к входному. Это повторяют на тысячах примеров.

**Виды сетей:** **свёрточные** — для изображений (распознавание лиц, медицинские снимки); **рекуррентные** и **трансформеры** — для последовательностей (текст, речь, перевод).

## Простая нейросеть в таблице
Нейрон можно собрать в Excel: столбцы входов, ячейки весов, формула суммы `=СУММПРОИЗВ(B2:C2; $F$1:$G$1) + $H$1` и функция активации `=ЕСЛИ(D2>=0; 1; 0)`. Меняя веса, можно добиться, чтобы нейрон правильно классифицировал все примеры из таблицы. Это ручная версия того, что обучение делает автоматически.

## Этика и риски
- **Предвзятость** — если обучающие данные несбалансированы, модель повторит перекос (например, хуже распознаёт определённые группы людей).
- **Приватность** — модели обучают на персональных данных.
- **Дипфейки и дезинформация** — правдоподобные поддельные фото, видео и голос.
- **Ответственность** — кто отвечает за ошибку беспилотника или медицинской системы.
- **Галлюцинации** языковых моделей — уверенные, но неверные ответы. Важные факты нужно проверять.

@terms
- Искусственный интеллект :: системы, решающие задачи, требующие человеческого мышления
- Тест Тьюринга :: проверка, можно ли отличить машину от человека в переписке
- Машинное обучение :: поиск закономерностей в данных без готовых правил
- Обучение с учителем :: обучение на примерах с правильными ответами
- Кластеризация :: разбиение объектов на группы похожих без готовых меток
- Переобучение :: модель запомнила обучающие данные и плохо работает на новых
- Перцептрон :: модель искусственного нейрона с весами и функцией активации
- Функция активации :: правило, превращающее взвешенную сумму в выход нейрона
- Скрытый слой :: слой нейронов между входным и выходным
- Глубокое обучение :: обучение нейросетей с множеством скрытых слоёв
