## Что такое CSS
**CSS** (Cascading Style Sheets, каскадные таблицы стилей) отвечает за внешний вид страницы: шрифты, цвета, отступы, расположение блоков. HTML описывает содержание, CSS — оформление. Одно и то же содержание можно показать по-разному, поменяв только стиль.

**Правило CSS** состоит из селектора и блока объявлений:

```css
h1 {
  color: #1F4FC1;        /* свойство: значение; */
  font-size: 32px;
}
```

## Три способа подключить стили
| Способ | Как пишется | Когда использовать |
|---|---|---|
| Встроенный (inline) | `<p style="color: red;">` | одно исключение для одного элемента |
| Внутренний | `<style> p { color: red; } </style>` в `<head>` | стили одной страницы |
| Внешний | `<link rel="stylesheet" href="style.css">` в `<head>` | общий файл стилей для всего сайта — лучший вариант |

**Каскадирование** — если для элемента сработало несколько правил, побеждает более приоритетное: встроенный стиль сильнее селектора `#id`, `#id` сильнее `.класса`, а класс сильнее селектора тега. При равном приоритете побеждает правило, записанное позже. Многие свойства (цвет, шрифт) **наследуются** вложенными элементами.

## Селекторы
| Селектор | Пример | Выбирает |
|---|---|---|
| Тега | `p { }` | все абзацы |
| Класса | `.note { }` + `<p class="note">` | все элементы с этим классом (можно много) |
| Идентификатора | `#menu { }` + `<div id="menu">` | один элемент с уникальным id |
| Контекстный (потомка) | `nav a { }` | ссылки внутри `nav` |
| Группа | `h1, h2 { }` | и h1, и h2 |
| Псевдокласс | `a:hover { }` | ссылку под курсором мыши |
| Универсальный | `* { }` | все элементы |

## Основные свойства
**Текст и шрифт:** `font-family: Arial, sans-serif;` · `font-size: 16px;` · `font-weight: bold;` · `font-style: italic;` · `text-align: center;` · `text-decoration: underline;` · `line-height: 1.5;` · `color: #333;`.

**Фон:** `background-color: #F0F3F8;` · `background-image: url(bg.png);`.

**Блочная модель.** Каждый элемент — прямоугольник из слоёв: **содержимое** (`width`, `height`) → **внутренний отступ** `padding` → **рамка** `border` → **внешний отступ** `margin`.

```css
.card {
  width: 300px;
  padding: 16px;              /* внутри рамки */
  border: 1px solid #CCC;     /* толщина, стиль, цвет */
  margin: 20px auto;          /* снаружи; auto по бокам — по центру */
}
```

**Расположение блоков:** `display: block | inline | none` (none — спрятать), `float: left` (обтекание), `display: flex` (элементы в ряд с выравниванием), `display: grid` (сетка), `position: relative | absolute | fixed` (точное положение).

**Единицы:** `px` — пиксели, `%` — от родителя, `em` и `rem` — от размера шрифта.

## Мультимедиа
```html
<audio src="kui.mp3" controls></audio>
<video src="lesson.mp4" width="640" controls poster="cover.jpg">
  Ваш браузер не поддерживает видео.
</video>
```

| Атрибут | Значение |
|---|---|
| `controls` | показать кнопки воспроизведения |
| `autoplay` | начать сразу (браузеры разрешают, только если звук выключен — `muted`) |
| `loop` | повторять по кругу |
| `muted` | без звука |
| `poster` | картинка до запуска видео |

Форматы: звук — MP3, OGG, WAV; видео — MP4, WebM, OGG. Видео с YouTube и карты встраивают тегом `<iframe src="...">`, который показывает другую страницу внутри вашей.

## Скрипты на JavaScript
**JavaScript** — язык программирования, который выполняется в браузере и делает страницу интерактивной: реагирует на нажатия, проверяет формы, меняет содержимое без перезагрузки.

Код пишут в теге `<script>` или подключают файлом `<script src="app.js"></script>`.

```html
<input id="age" type="number" placeholder="Возраст">
<button onclick="check()">Проверить</button>
<p id="out"></p>
<script>
  function check() {
    let age = Number(document.getElementById("age").value);
    let text = age >= 18 ? "Можно голосовать" : "Пока рано";
    document.getElementById("out").textContent = text;
  }
</script>
```

- `let` и `const` объявляют переменные, `function` — функцию;
- **события**: `onclick` (щелчок), `onmouseover` (наведение), `onchange` (изменение поля), `onload` (страница загрузилась);
- `alert("текст")` показывает окно с сообщением, `prompt()` — окно с вводом, `document.write()` пишет в страницу (устаревший способ);
- `document.getElementById("id")` находит элемент, чтобы изменить его текст или стиль.

@terms
- CSS :: язык описания внешнего вида веб-страниц
- Селектор :: часть правила CSS, указывающая, к каким элементам применить стиль
- Класс :: атрибут class, общий для группы элементов; в CSS — .имя
- Идентификатор :: уникальный атрибут id элемента; в CSS — #имя
- Каскадирование :: правила выбора стиля, если к элементу применимо несколько правил
- Блочная модель :: содержимое, padding, border и margin элемента
- JavaScript :: язык программирования, выполняемый в браузере
- Событие :: действие пользователя или браузера, на которое реагирует скрипт
