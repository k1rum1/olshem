## Что такое компьютерная сеть
**Компьютерная сеть** — это компьютеры и другие устройства, соединённые каналами связи и сетевым оборудованием, чтобы обмениваться данными и вместе пользоваться ресурсами: файлами, принтерами, базами данных, доступом в интернет. Объединение нескольких сетей в одну большую называют **межсетевым взаимодействием**, а самый большой пример такого объединения — интернет.

Чтобы сеть работала, нужны три вещи:
1. **Сетевые интерфейсы** — через них устройство подключается к сети (сетевой адаптер).
2. **Протоколы** — общие правила обмена данными.
3. **Сетевые службы** — то, что один компьютер делает для другого: отдаёт файлы, печатает, пересылает почту.

Программно-аппаратные компоненты сети: компьютеры, сетевое оборудование, сетевые операционные системы и сетевые приложения.

> Интернет в Казахстане отсчитывают от **19 сентября 1994 года**: в этот день зарегистрировали национальный домен верхнего уровня **.kz**.

## Виды сетей
**По охвату территории:**

| Вид | Расшифровка | Пример |
|---|---|---|
| PAN | Personal Area Network, персональная | телефон + наушники + ноутбук одного человека |
| LAN | Local Area Network, локальная | сеть школьного кабинета, офиса, дома |
| MAN | Metropolitan Area Network, городская | сеть провайдера в пределах города |
| WAN | Wide Area Network, глобальная | интернет |

**По способу организации:**
- **Клиент-сервер.** **Сервер** даёт общий доступ к ресурсам (файловый, почтовый, сервер печати, сервер приложений), **клиент** этими ресурсами пользуется: отправляет запрос и получает ответ.
- **Одноранговая сеть.** Все компьютеры равноправны, каждый может быть и клиентом, и сервером. Подходит для маленьких сетей.

**Топология** — схема соединения узлов. Основные: **шина** (все узлы на одном кабеле; обрыв кабеля останавливает всю сеть), **звезда** (все узлы подключены к центральному устройству — коммутатору; самая распространённая) и **кольцо** (данные идут по кругу от узла к узлу).

**VPN** (Virtual Private Network, виртуальная частная сеть) — защищённая сеть поверх интернета. Например, она объединяет локальные сети филиалов одной компании в разных городах. Данные идут по зашифрованному «туннелю», поэтому посторонние их не прочитают.

## Сетевое оборудование
**Узел сети** (node) — любое устройство, подключённое к сети: компьютер, телефон, принтер, а также маршрутизатор или коммутатор.

| Устройство | Что делает |
|---|---|
| Сетевой адаптер (сетевая карта, NIC) | подключает узел к сети; бывает проводным (Ethernet) и беспроводным (Wi-Fi, Bluetooth). У каждого адаптера есть уникальный MAC-адрес |
| Концентратор (хаб) | получает пакет на один порт и рассылает его **на все** остальные порты |
| Коммутатор (switch) | соединяет устройства одного сегмента сети и отправляет пакет **только получателю**; запоминает в таблице, какой адрес на каком порту |
| Маршрутизатор (роутер, router) | пересылает пакеты **между разными сетями** по таблице маршрутизации; дома раздаёт интернет по кабелю и Wi-Fi |
| Модем | **мо**дуляция и **дем**одуляция: превращает цифровой сигнал в аналоговый для линии связи и обратно; скорость измеряют в бит/с |

Коммутатор работает быстрее маршрутизатора, потому что не анализирует каждый пакет, но маршрутизатор лучше подходит для больших сетей и связи с интернетом.

**MAC-адрес** — уникальный физический адрес сетевого адаптера длиной **6 байт (48 бит)**. Его задаёт производитель. Записывают шестью парами шестнадцатеричных цифр: `00-1A-2B-3C-4D-5E`. В одной сети Ethernet не может быть двух адаптеров с одинаковым MAC-адресом.

## Протоколы
**Протокол** — набор правил передачи данных, общий «язык» устройств. В интернете используют стек **TCP/IP**: **IP** отвечает за адресацию и доставку пакетов, **TCP** — за надёжную передачу (пакеты собираются в правильном порядке, потерянные пересылаются).

| Протокол | Для чего |
|---|---|
| HTTP / HTTPS | открытие веб-страниц (HTTPS — с шифрованием) |
| FTP | передача файлов |
| SMTP | отправка электронной почты |
| POP3 | получение почты с сервера на компьютер |
| IMAP | чтение почты прямо на сервере, без скачивания |
| DHCP | автоматически выдаёт устройствам IP-адреса |
| DNS | переводит доменные имена в IP-адреса |

## IP-адрес
**IP-адрес** — уникальный адрес устройства в сети, по которому ему доставляют данные. Как почтовый адрес: без него письмо не дойдёт.

**IPv4** — 32-битный адрес. Записывают четырьмя числами от 0 до 255 через точку. Каждое число — один байт, его называют **октетом**:

```
192.168.65.79 = 11000000.10101000.01000001.01001111
```

Всего адресов IPv4: 2³² = 4 294 967 296, и их уже не хватает. Поэтому в 1996 году предложили **IPv6** — 128-битные адреса, которые записывают восемью группами шестнадцатеричных цифр: `21DA:00D3:0000:2F3B:02AA:00FF:FE28:9C5A`.

**Внутренние и внешние адреса.** Внутренние («серые», частные) работают только внутри локальной сети, например диапазон `192.168.0.0 – 192.168.255.255`. Внешний («белый», публичный) адрес уникален во всём интернете. Его выдаёт **провайдер** (ISP, поставщик интернет-услуг).

**Статический и динамический адрес.** Статический закреплён за устройством и не меняется. Динамический выдаётся на время (обычно по DHCP) и может смениться при следующем подключении.

**Классы адресов** (старая схема, но встречается в задачах):

| Класс | Первый октет | Бит на сеть / на узел |
|---|---|---|
| A | 0–127 | 8 / 24 |
| B | 128–191 | 16 / 16 |
| C | 192–223 | 24 / 8 |
| D | 224–239 | групповая рассылка |
| E | 240–255 | зарезервирован |

## Маска подсети
IP-адрес делится на две части: **номер сети** и **номер узла** в этой сети. Где проходит граница, показывает **маска подсети** — тоже 32 бита. В маске сначала идут только единицы, потом только нули. Например, `255.255.255.0` = 24 единицы. Сокращённая запись: `192.168.1.1/24`.

> Маска `255.255.128.255` невозможна: после нулей снова идут единицы.

**Адрес сети** получают поразрядной конъюнкцией (логическим И) IP-адреса и маски:

```
IP     192.168.11.10  = 11000000.10101000.00001011.00001010
Маска  255.255.248.0  = 11111111.11111111.11111000.00000000
И      192.168.8.0    = 11000000.10101000.00001000.00000000
```

**Номер узла** — это биты адреса там, где в маске нули. В примере это последние 11 бит: `011 00001010` = 778.

**Сколько узлов в подсети.** Если в маске n нулей, адресов 2ⁿ. Два из них заняты: адрес самой сети (все биты узла — нули) и широковещательный адрес (все биты узла — единицы). Поэтому:

```
K = 2ⁿ − 2
```

Пример: маска `255.255.255.128` → нулей 7 → 2⁷ − 2 = **126** узлов.

## Доменные имена и DNS
Запоминать числа неудобно, поэтому у сайтов есть **доменные имена**. Имя читают справа налево, от общего к частному: в `www.smk.edu.kz` домен первого (верхнего) уровня — `kz`, второго — `edu.kz`, третьего — `smk.edu.kz`.

- Домены верхнего уровня бывают **географические** (`.kz`, `.ru`, `.fr`) и **тематические** (`.com` — коммерция, `.edu` — образование, `.gov` — государство, `.org` — организации).
- Часть имени между точками — до 63 символов, всё имя — до 255.

**DNS** (Domain Name System) — служба, которая переводит доменное имя в IP-адрес. Браузер сначала спрашивает DNS-сервер: «какой адрес у www.icann.org?», а потом соединяется с полученным IP.

**URL** — полный адрес ресурса: `https://www.site.kz/news/index.html`. Он состоит из протокола (`https`), доменного имени (`www.site.kz`) и пути к файлу (`/news/index.html`).

## Практика: команды сети
В Windows откройте командную строку (Win+R → `cmd`):
- `ipconfig /all` — показывает IP-адрес, маску, MAC-адрес («физический адрес»), DNS-серверы и включён ли DHCP;
- `ping www.icann.org` — проверяет связь с узлом и показывает, в какой IP-адрес DNS превратил имя;
- `tracert www.icann.org` — показывает, через какие маршрутизаторы идут пакеты.

@terms
- Компьютерная сеть :: устройства, соединённые каналами связи для обмена данными и совместного использования ресурсов
- Узел сети :: любое устройство, подключённое к сети
- Протокол :: набор правил передачи данных между устройствами
- IP-адрес :: уникальный адрес устройства в сети; в IPv4 — 32 бита, в IPv6 — 128 бит
- Октет :: один байт (8 бит) IP-адреса, число от 0 до 255
- Маска подсети :: 32-битный шаблон, который отделяет номер сети от номера узла
- MAC-адрес :: 48-битный физический адрес сетевого адаптера, задаётся производителем
- Маршрутизатор :: устройство, пересылающее пакеты между сетями
- Коммутатор :: устройство, передающее пакет только получателю внутри сегмента сети
- Концентратор :: устройство, рассылающее пакет на все порты
- DNS :: служба перевода доменных имён в IP-адреса
- VPN :: защищённая виртуальная частная сеть поверх интернета
- Провайдер (ISP) :: компания, предоставляющая доступ в интернет
