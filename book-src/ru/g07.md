## Строка — последовательность символов
**Строка** (`str`) — упорядоченная последовательность символов в кавычках: `'Тараз'` или `"Тараз"`.

**Индексы** считаются с нуля. Отрицательные индексы считают с конца:

```python
s = "ИНФОРМАТИКА"
#    0123456789...
s[0]     # 'И'
s[3]     # 'О'
s[-1]    # 'А' — последний символ
len(s)   # 11
```

**Срез** `s[a:b:c]` — символы с индекса a **до** b (b не включается) с шагом c:

```python
s[0:4]   # 'ИНФО'
s[4:]    # 'РМАТИКА'
s[:-3]   # 'ИНФОРМАТ'
s[::2]   # 'ИФРАИА' — каждый второй
s[::-1]  # 'АКИТАМРОФНИ' — строка наоборот
```

> Строки **неизменяемы**: `s[0] = 'и'` вызовет ошибку. Чтобы «изменить» строку, создают новую: `s = 'и' + s[1:]`.

**Операции:** `+` — склеивание (конкатенация), `*` — повторение (`'ab' * 3` → `'ababab'`), `in` — проверка вхождения (`'ФОР' in s` → `True`), сравнение строк идёт по кодам символов.

**Перебор символов:**

```python
vowels = 0
for ch in "алгоритм":
    if ch in "аеёиоуыэюя":
        vowels += 1
print(vowels)  # 3
```

## Строковые методы
Методы не меняют исходную строку, а возвращают новую.

| Метод | Что делает | Пример → результат |
|---|---|---|
| `upper()`, `lower()` | все буквы заглавные / строчные | `'Python'.upper()` → `'PYTHON'` |
| `capitalize()`, `title()` | первая буква заглавная / каждое слово с заглавной | `'тараз'.title()` → `'Тараз'` |
| `find(x)` | индекс первого вхождения, −1 если нет | `'банан'.find('н')` → `2` |
| `index(x)` | как find, но ошибка, если нет | |
| `count(x)` | сколько раз встречается | `'банан'.count('а')` → `2` |
| `replace(a, b)` | заменить все a на b | `'2+2'.replace('+', '*')` → `'2*2'` |
| `split(sep)` | разбить в список по разделителю (по умолчанию пробелы) | `'a b c'.split()` → `['a', 'b', 'c']` |
| `sep.join(list)` | склеить список строк через sep | `'-'.join(['1','2'])` → `'1-2'` |
| `strip()` | убрать пробелы и переносы по краям | `'  hi \n'.strip()` → `'hi'` |
| `startswith(x)`, `endswith(x)` | начинается / заканчивается на x | |
| `isdigit()`, `isalpha()` | только цифры / только буквы | `'2025'.isdigit()` → `True` |

**Коды символов:** `ord('A')` → `65`, `chr(66)` → `'B'`.

**Форматирование:** `f"Балл: {score}, процент: {p:.1f}%"` подставляет значения переменных, `:.1f` — один знак после запятой.

**Пример: самое длинное слово в предложении.**

```python
text = "Жамбыл облысы информатика олимпиадасы"
words = text.split()
longest = max(words, key=len)
print(longest, len(longest))  # информатика 11 (при равной длине max берёт первое)
```

## Файлы
**Файл** — именованная область данных на диске. Файлы бывают **текстовые** (символы, можно открыть блокнотом: `.txt`, `.csv`, `.py`) и **двоичные** (картинки, программы, архивы).

Работа с файлом: **открыть → прочитать или записать → закрыть**.

```python
f = open("data.txt", "r", encoding="utf-8")
text = f.read()
f.close()
```

| Режим | Значение |
|---|---|
| `"r"` | чтение (по умолчанию); ошибка, если файла нет |
| `"w"` | запись; файл создаётся, а старое содержимое **стирается** |
| `"a"` | дозапись в конец файла |
| `"rb"`, `"wb"` | чтение и запись двоичных файлов |

**Способы чтения:**
- `f.read()` — весь файл одной строкой;
- `f.readline()` — одна следующая строка;
- `f.readlines()` — список всех строк;
- `for line in f:` — построчный перебор, экономит память.

**Запись:** `f.write("текст\n")` — записывает строку. Число сначала превращают в строку: `f.write(str(x))`.

Удобнее работать через **`with`**: файл закроется сам, даже при ошибке.

```python
with open("scores.txt", encoding="utf-8") as f:
    nums = [int(line) for line in f]
with open("result.txt", "w", encoding="utf-8") as out:
    out.write(f"Среднее: {sum(nums) / len(nums):.1f}\n")
```

> Указывайте `encoding="utf-8"`, иначе русские и казахские буквы могут прочитаться неправильно (см. главу «Кодирование»).

**Путь к файлу** бывает **относительным** (`data/scores.txt` — от папки программы) и **абсолютным** (`C:\Users\Student\scores.txt`).

@terms
- Строка :: неизменяемая последовательность символов
- Индекс :: номер символа в строке, начиная с 0
- Срез :: часть строки s[a:b:c], где b не включается
- Конкатенация :: склеивание строк операцией +
- Метод строки :: функция, вызываемая через точку: s.upper()
- Текстовый файл :: файл из символов, читаемый как текст
- Режим открытия :: способ работы с файлом: r, w, a
- with :: конструкция, автоматически закрывающая файл
