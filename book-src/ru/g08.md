## Сортировка
**Сортировка** — упорядочивание элементов по возрастанию или убыванию. Отсортированные данные легче искать и анализировать.

### Сортировка пузырьком (обменом)
Сравниваем соседние элементы и меняем местами, если они стоят неправильно. За один проход самый большой элемент «всплывает» в конец.

```python
def bubble(a):
    n = len(a)
    for i in range(n - 1):
        for j in range(n - 1 - i):
            if a[j] > a[j + 1]:
                a[j], a[j + 1] = a[j + 1], a[j]
    return a
```

Пример для `[5, 1, 4, 2]`: первый проход → `[1, 4, 2, 5]`, второй → `[1, 2, 4, 5]`.

### Сортировка выбором
Находим минимум среди неотсортированной части и ставим его на первое свободное место.

```python
def selection(a):
    for i in range(len(a) - 1):
        m = i
        for j in range(i + 1, len(a)):
            if a[j] < a[m]:
                m = j
        a[i], a[m] = a[m], a[i]
    return a
```

### Сортировка вставками
Берём следующий элемент и вставляем его на своё место среди уже отсортированных, как карты в руке. Быстро работает на почти отсортированных данных.

```python
def insertion(a):
    for i in range(1, len(a)):
        x, j = a[i], i - 1
        while j >= 0 and a[j] > x:
            a[j + 1] = a[j]
            j -= 1
        a[j + 1] = x
    return a
```

### Быстрая сортировка (Хоара)
Выбираем опорный элемент, делим массив на «меньше опорного» и «больше опорного» и рекурсивно сортируем обе части.

```python
def quick(a):
    if len(a) <= 1:
        return a
    p = a[len(a) // 2]
    return quick([x for x in a if x < p]) + [x for x in a if x == p] + quick([x for x in a if x > p])
```

### Сравнение
| Алгоритм | Сравнений в худшем случае | Когда хорош |
|---|---|---|
| Пузырьком | ≈ n²/2 | учебный, простой |
| Выбором | ≈ n²/2, но мало обменов | когда обмен «дорогой» |
| Вставками | ≈ n²/2, на почти отсортированных ≈ n | небольшие и почти упорядоченные данные |
| Быстрая | в среднем ≈ n·log₂n | большие массивы |

Запись **O(n²)** означает, что время растёт пропорционально квадрату количества элементов: при n = 1000 — около миллиона сравнений. **O(n log n)** — около 10 000.

В Python есть готовые функции: `sorted(a)` возвращает новый отсортированный список, `a.sort()` сортирует сам список. Параметры: `reverse=True` — по убыванию, `key=len` — сортировка по длине.

## Поиск
**Линейный поиск** проверяет элементы по очереди: до n сравнений.

**Бинарный (двоичный) поиск** работает только в **отсортированном** массиве. Смотрим средний элемент: если искомое меньше — ищем в левой половине, если больше — в правой. Каждый шаг делит область поиска пополам, поэтому нужно не больше ⌈log₂(n+1)⌉ сравнений: для 1000 элементов — 10.

```python
def binary_search(a, x):
    lo, hi = 0, len(a) - 1
    while lo <= hi:
        mid = (lo + hi) // 2
        if a[mid] == x:
            return mid
        if a[mid] < x:
            lo = mid + 1
        else:
            hi = mid - 1
    return -1
```

## Графы
**Граф** — набор **вершин** (узлов) и **рёбер** (связей между ними). Графом можно описать карту дорог, компьютерную сеть, друзей в соцсети, зависимость тем в учебной программе.

- **Неориентированный** граф — рёбра без направления (дорога в обе стороны).
- **Ориентированный** граф (орграф) — рёбра-стрелки, их называют **дугами** (подписка в соцсети, улица с односторонним движением).
- **Взвешенный** граф — у рёбер есть числа: расстояние, время, стоимость.
- **Степень вершины** — сколько рёбер из неё выходит.
- **Путь** — последовательность вершин, соединённых рёбрами. **Цикл** — путь, который возвращается в начальную вершину.
- **Дерево** — связный граф без циклов. В дереве из n вершин ровно n − 1 рёбер.

**Как хранить граф в программе:**
- **Матрица смежности** — таблица n × n: на пересечении строки i и столбца j стоит 1 (или вес), если есть ребро i–j. У неориентированного графа матрица симметрична.
- **Список смежности** — для каждой вершины список соседей: `{'A': ['B', 'C'], 'B': ['A'], ...}`.

|   | A | B | C | D |
|---|---|---|---|---|
| A | 0 | 4 | 1 | 0 |
| B | 4 | 0 | 2 | 5 |
| C | 1 | 2 | 0 | 8 |
| D | 0 | 5 | 8 | 0 |

## Алгоритмы на графах
**Обход в ширину (BFS)** — сначала посещаем всех соседей стартовой вершины, потом соседей соседей. Использует очередь и находит путь с наименьшим числом рёбер.

**Обход в глубину (DFS)** — идём по одной ветке, пока можно, потом возвращаемся. Использует стек или рекурсию.

```python
from collections import deque
def bfs(graph, start):
    seen, order, q = {start}, [], deque([start])
    while q:
        v = q.popleft()
        order.append(v)
        for u in graph[v]:
            if u not in seen:
                seen.add(u)
                q.append(u)
    return order
```

**Кратчайший путь во взвешенном графе — алгоритм Дейкстры:**
1. Расстояние до старта 0, до остальных ∞.
2. Берём непосещённую вершину с наименьшим расстоянием и помечаем её посещённой.
3. Для каждого её соседа пробуем улучшить расстояние: `d[сосед] = min(d[сосед], d[v] + вес)`.
4. Повторяем, пока есть непосещённые вершины.

По таблице выше кратчайший путь A → D: A → C → B → D = 1 + 2 + 5 = **8** (а не прямо через C: 1 + 8 = 9).

> Теория графов началась с задачи Эйлера о семи мостах Кёнигсберга (1736): обойти все мосты по одному разу нельзя, потому что у всех четырёх «вершин» нечётная степень.

@terms
- Сортировка :: упорядочивание элементов по возрастанию или убыванию
- Сортировка пузырьком :: обмен соседних элементов, стоящих в неправильном порядке
- Сортировка выбором :: поиск минимума и перенос его в начало неотсортированной части
- Быстрая сортировка :: деление массива относительно опорного элемента и рекурсивная сортировка частей
- Бинарный поиск :: поиск в отсортированном массиве делением пополам
- Граф :: множество вершин и рёбер между ними
- Взвешенный граф :: граф, у рёбер которого есть числовые веса
- Матрица смежности :: таблица n × n, описывающая рёбра графа
- Дерево :: связный граф без циклов
- Алгоритм Дейкстры :: поиск кратчайших путей от одной вершины во взвешенном графе
