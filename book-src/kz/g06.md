## Ішкі бағдарламалар не үшін керек
**Ішкі бағдарлама** — бағдарламаның көп рет шақыруға болатын атаулы бөлігі. Ол кодтың қайталануын жояды, қателерді іздеуді жеңілдетеді және есепті бөліктерге бөлуге мүмкіндік береді.

Ішкі бағдарламалардың екі түрі бар:
- **процедура** әрекеттер орындайды (мысалы, басып шығарады), бірақ ештеңе қайтармайды;
- **функция** мәнді есептеп, оны `return` арқылы **қайтарады**.

Python-да екеуі де `def` сөзімен жарияланады. Процедура — `return`-сіз функция: ол `None` қайтарады.

```python
def greet(name):          # процедура: тек басып шығарады
    print("Сәлем,", name)

def square(x):            # функция: нәтижені қайтарады
    return x * x

greet("Айгерім")
y = square(5) + 1         # y = 26
```

## Параметрлер және аргументтер
- **Параметрлер (формалды)** — функция тақырыбындағы атаулар: `def area(a, b):`.
- **Аргументтер (нақты)** — шақыру кезіндегі мәндер: `area(3, 4)`.

```python
def area(a, b=1):         # b = 1 — әдепкі мән
    return a * b

area(3, 4)                # 12, позициялық аргументтер
area(5)                   # 5, b әдепкі бойынша алынды
area(b=2, a=7)            # 14, атаулы аргументтер
```

Функция бірден бірнеше мән қайтара алады: `return s, p` — және оларды қабылдауға болады: `s, p = calc(3, 4)`.

> Python-да сандар, жолдар және кортеждер өзгермейді: функция ішінде параметрді өзгертсе, сырттағы айнымалы өзгермейді. Тізім өзгермелі: функция ішіндегі `lst.append(...)` бастапқы тізімді өзгертеді.

## Жергілікті және ғаламдық айнымалылар
- **Жергілікті** айнымалы функция ішінде құрылады және тек сонда көрінеді.
- **Ғаламдық** айнымалы функциялардан тыс құрылады және барлық жерде көрінеді. Оны функция ішінде **өзгерту** үшін `global` деп жариялау керек.

```python
count = 0                 # ғаламдық

def add():
    global count
    count += 1            # global болмаса, мұнда қате шығады
    temp = 10             # жергілікті, сыртта көрінбейді

add()
print(count)              # 1
```

Деректерді ғаламдық айнымалылар арқылы емес, параметрлер мен `return` арқылы беру — жақсы тәжірибе.

Python-ның **кірістірілген функциялары** пайдалануға дайын: `len`, `abs`, `max`, `min`, `sum`, `round`, `int`, `str`, `input`, `print`. Қосымша функциялар **модульдерден** қосылады: `import math` → `math.sqrt(16)`.

**Атаусыз функция** `lambda` бір жолда жазылады: `sq = lambda x: x * x`. Оны көбіне сұрыптау кілті ретінде пайдаланады.

## Рекурсия
**Рекурсия** — функцияның өзін-өзі шақыруы. Рекурсивті функцияда міндетті түрде екі бөлік болады:
1. **Базалық жағдай** — функция жаңа шақырусыз жауап қайтаратын шарт. Онсыз шақырулар шексіз болады, және бағдарлама `RecursionError` қатесімен аяқталады.
2. **Рекурсивті қадам** — қарапайымырақ есеп үшін өзін шақыру.

**Факториал**: n! = n · (n − 1)!, 0! = 1.

```python
def fact(n):
    if n <= 1:            # базалық жағдай
        return 1
    return n * fact(n - 1)  # рекурсивті қадам

fact(4)  # 4 · 3 · 2 · 1 = 24
```

Бұл қалай жұмыс істейді: `fact(4)` `fact(3)`-ті күтеді, ол `fact(2)`-ні, ол — `fact(1)`-ді. Аяқталмаған шақырулар **шақырулар стегінде** сақталады. `fact(1)` 1 қайтарғанда стек «шешіледі»: 2·1 = 2, 3·2 = 6, 4·6 = 24.

**Фибоначчи сандары**: F(1) = F(2) = 1, F(n) = F(n−1) + F(n−2).

```python
def fib(n):
    if n <= 2:
        return 1
    return fib(n - 1) + fib(n - 2)
```

> Мұндай функция бір мәндерді қайта-қайта есептейді және n = 40 болғанда өте ұзақ жұмыс істейді. Цикл есепті жылдамырақ шешеді. Рекурсия есеп ұқсас ішкі есептерге табиғи түрде бөлінетін жерде ыңғайлы: ағашты аралау, біріктіру арқылы сұрыптау, нұсқаларды іріктеу.

**Евклид алгоритмі бойынша ЕҮОБ**: ЕҮОБ(a, b) = ЕҮОБ(b, a mod b), ЕҮОБ(a, 0) = a.

```python
def gcd(a, b):
    if b == 0:
        return a
    return gcd(b, a % b)

gcd(48, 18)  # 6
```

**ҰБТ есептеріндегі трассировка.** Рекурсивті функцияның не шығаратынын жиі сұрайды. Шақыруларды бағанмен және кері жолдағы мәндерді жазып шығыңыз:

```python
def f(n):
    if n > 0:
        print(n, end=' ')
        f(n - 2)
f(7)   # 7 5 3 1
```

@terms
- Ішкі бағдарлама :: бағдарламаның көп рет шақыруға болатын атаулы бөлігі
- Процедура :: мән қайтармай әрекеттер орындайтын ішкі бағдарлама
- Функция :: return арқылы мән қайтаратын ішкі бағдарлама
- Параметр :: функция тақырыбындағы айнымалының атауы
- Аргумент :: шақыру кезінде функцияға берілетін мән
- Жергілікті айнымалы :: тек функция ішінде көрінетін айнымалы
- Ғаламдық айнымалы :: функциялардан тыс құрылған айнымалы
- Рекурсия :: функцияның өзін-өзі шақыруы
- Базалық жағдай :: рекурсия тоқтайтын шарт
- Шақырулар стегі :: аяқталмаған функция шақырулары сақталатын жад

@added
- Рекурсия, базалық жағдай және шақырулар стегі Атамұрада ең толық талданған. Арман-ПВ-да рекурсия бір рет аталады.
- Фибоначчи сандарын Алматыкітап пен Арман-ПВ, Евклид алгоритмін Алматыкітап пен Атамұра келтіреді.
- Әдепкі мәндер мен lambda тек Арман-ПВ-да, global кілт сөзі Алматыкітап пен Атамұрада бар.
- Атаулы аргументтер, бірнеше мән қайтару, өзгермелі және өзгермейтін аргументтердің айырмасы, RecursionError қатесі және рекурсия трассировкасын талдау қосылды. ҰБТ-да мұндай есептер көп.
