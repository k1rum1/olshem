# HTML белгілеу тілі
grade: 10
ent: 13
summary: Веб-бет неден тұрады, мәтінді, тізімдерді, кестелерді, суреттер мен сілтемелерді HTML тілінде қалай белгілейді.

## Сайт және веб-бет
**Веб-бет** — браузер пайдаланушыға көрсететін құжат. **Сайт** — ортақ мекенжайы (домені) бар байланысты беттер жиыны.

- **Статикалық** сайт — беттер алдын ала жазылған және барлық келушілерге бірдей.
- **Динамикалық** сайт — беттер «жүріп бара жатып», көбіне дерекқордан жиналады: интернет-дүкен, электрондық күнделік.

**Сайт жасау кезеңдері:** мақсат және аудитория → құрылым (беттер картасы) → дизайн → беттеу (HTML және CSS) → толтыру → тексеру → хостингке орналастыру.

Сайтты **конструкторда** (Tilda, Wix — кодсыз) жасауға немесе кодты редакторда қолмен жазуға болады: Блокнот, Notepad++, Visual Studio Code.

## Тегтер және құжат құрылымы
**HTML** (HyperText Markup Language) — белгілеу тілі: ол бетте **не** тұрғанын сипаттайды (тақырып, абзац, кесте), ал оның қалай көрінетінін емес. Безендіруді CSS береді.

**Тег** — бұрыштық жақшадағы команда. Тегтердің көбі **жұп**: ашатын `<p>` және жабатын `</p>`. **Жалқы** тегтер жабылмайды: `<br>`, `<img>`, `<hr>`, `<meta>`.

**Атрибут** тегті нақтылайды: `<img src="logo.png" alt="Логотип" width="200">`. Мұнда `src`, `alt`, `width` — атрибуттар, тырнақшада — олардың мәндері.

```html
<!DOCTYPE html>
<html lang="kk">
<head>
  <meta charset="utf-8">
  <title>Менің мектебім</title>
</head>
<body>
  <h1>№1 мектеп-гимназия</h1>
  <p>Қош келдіңіз!</p>
</body>
</html>
```

- `<!DOCTYPE html>` — браузерге бұл HTML5 екенін хабарлайды;
- `<head>` — қызметтік бөлім: кодировка, `<title>` қойынды тақырыбы, стильдерді қосу;
- `<body>` — бетте көрінетіннің бәрі.

Файл `.html` кеңейтімімен сақталады, сайттың басты беті әдетте `index.html` деп аталады.

## Мәтін
| Тег | Мақсаты |
|---|---|
| `<h1>` … `<h6>` | алты деңгейлі тақырыптар, `h1` — ең ірісі |
| `<p>` | абзац |
| `<br>` | жолды тасымалдау |
| `<hr>` | көлденең сызық |
| `<b>`, `<strong>` | жуан (`strong` — мағынасы бойынша «маңызды» да) |
| `<i>`, `<em>` | курсив (`em` — мағыналық бөлектеу) |
| `<u>` | асты сызылған |
| `<sub>`, `<sup>` | төменгі және жоғарғы индекс: H`<sub>`2`</sub>`O, x`<sup>`2`</sup>` |

`align` атрибуты (`left`, `center`, `right`) мәтінді туралайды, ал `<font color="red" size="5" face="Arial">` тегі қаріпті өзгертеді. Екі тәсіл де **ескірген**: HTML5-те безендіру CSS арқылы беріледі.

**Түсті** атауымен (`red`) немесе `#RRGGBB` он алтылық кодымен береді: әр жұп — `00`-ден `FF`-ке дейінгі қызыл, жасыл және көк түстердің қарқындылығы. `#FF0000` — қызыл, `#000000` — қара, `#FFFFFF` — ақ.

## Тізімдер
```html
<ul>                  <!-- маркерленген -->
  <li>Python</li>
  <li>HTML</li>
</ul>
<ol type="1" start="3">  <!-- нөмірленген, 3-тен -->
  <li>Талдау</li>
  <li>Дизайн</li>
</ol>
```

`<ol>` тегінің `type` атрибуты нөмірлеу түрін береді: `1`, `A`, `a`, `I`, `i`. Сондай-ақ **анықтамалар тізімі** `<dl>` бар: термин `<dt>` және анықтама `<dd>`.

## Кестелер
```html
<table border="1">
  <tr>
    <th>Пән</th><th>Балл</th>
  </tr>
  <tr>
    <td>Информатика</td><td>95</td>
  </tr>
  <tr>
    <td colspan="2">Барлығы: 1 пән</td>
  </tr>
</table>
```

- `<table>` — кесте, `<tr>` — жол, `<td>` — ұяшық, `<th>` — тақырып ұяшығы (жуан, ортада);
- `colspan="2"` екі ұяшықты көлденеңінен, `rowspan="2"` — тігінен біріктіреді;
- `border`, `cellpadding`, `cellspacing`, `width` — безендірудің ескірген атрибуттары, қазір олар CSS-те беріледі.

## Суреттер мен сілтемелер
**Сурет:** `<img src="photo.jpg" alt="Сипаттама" width="300">`. `alt` атрибуты — сурет жүктелмесе көрсетілетін мәтін; оны көзі нашар көретіндерге арналған бағдарламалар оқиды. Сайттарға арналған пішімдер: JPEG — фотосуреттер, PNG — мөлдір суреттер, GIF — қарапайым анимация, SVG — векторлық графика.

**Гиперсілтеме** — `href` атрибуты бар `<a>` тегі:

```html
<a href="about.html">Мектеп туралы</a>                 <!-- сайттың бетіне -->
<a href="https://edu.gov.kz" target="_blank">ОМ</a>   <!-- жаңа қойындыда -->
<a href="mailto:info@school.kz">Хат жазу</a>          <!-- хат -->
<a href="#contacts">Байланыс</a>                      <!-- осы беттегі якорь -->
<h2 id="contacts">Байланыс</h2>
```

Сурет те сілтеме бола алады: `<a href="index.html"><img src="logo.png" alt="Басты бетке"></a>`.

**Файлдарға жолдар** **абсолютті** (`https://site.kz/img/a.png`) және **салыстырмалы** (`img/a.png` — ағымдағы беттен, `../a.png` — бір қалта жоғары) болады.

## HTML5-тегі бет құрылымы
Блоктарды белгілеу үшін әмбебап `<div>` (блок) және `<span>` (жолдың бөлігі) тегтерін, сондай-ақ блоктың мағынасын өздері айтатын **семантикалық** тегтерді пайдаланады: `<header>` — жоғарғы бөлік, `<nav>` — мәзір, `<main>` — негізгі мазмұн, `<section>` — бөлім, `<article>` — мақала, `<aside>` — бүйір баған, `<footer>` — төменгі бөлік.

Кодтың дұрыстығын W3C валидаторымен тексереді: validator.w3.org.
