## Дерекқорды жобалау
1. **Пәндік саланы талдау** — қандай объектілер және базаға қандай сұрақтар болады. Мысалы, «мектеп»: оқушылар, сыныптар, пәндер, бағалар.
2. **Кестелер мен өрістерді бөлу** — объектілердің әр түріне бір кесте, әр өрістің өз типі.
3. **Бастапқы кілттер мен байланыстарды таңдау** — кестелер арасында **деректер сұлбасын** құрады.
4. **Құру** — ДҚБЖ-да кестелер (Access-те — **Конструктор** режимінде) немесе SQL командасымен.
5. **Деректерді енгізу** — қолмен, **формалар** арқылы немесе импорттап.
6. **Сұраулар мен есептер** — жауаптарды алу.

**ДҚБЖ объектілері (Access мысалында):**

| Объект | Мақсаты |
|---|---|
| Кесте | деректерді сақтайды |
| Форма | бір жазбаны енгізуге және қарауға ыңғайлы терезе; енгізу қателерінен қорғайды |
| Сұрау | деректерді шарт бойынша іріктейді, сұрыптайды, санайды және өзгертеді |
| Есеп | басып шығаруға безендірілген нәтиже: топтауы, қорытындылары, тақырыптары бар |

## SQL
**SQL** (Structured Query Language) — реляциялық дерекқорларға құрылымдық сұраулар тілі. Оны барлық ДҚБЖ түсінеді. Кілт сөздерді бас әріппен жазу қабылданған.

**Кесте мен деректерді құру:**

```sql
CREATE TABLE students (
  id INTEGER PRIMARY KEY,
  name TEXT,
  class TEXT,
  score INTEGER
);
INSERT INTO students (id, name, class, score) VALUES (1, 'Айдана', '10А', 92);
UPDATE students SET score = 95 WHERE id = 1;
DELETE FROM students WHERE score < 20;
```

## Іріктеу: SELECT
```sql
SELECT name, score          -- қай өрістер (* — барлығы)
FROM students               -- қай кестеден
WHERE class = '10А'         -- іріктеу шарты
ORDER BY score DESC;        -- сұрыптау: ASC өсу, DESC кему ретімен
```

**WHERE ішіндегі шарттар:**
- салыстырулар: `=`, `<>` (тең емес), `<`, `>`, `<=`, `>=`;
- логика: `AND`, `OR`, `NOT`;
- `BETWEEN 60 AND 80` — шекаралары қоса алынған ауқым;
- `IN ('10А', '10Б')` — мәндердің бірі;
- `LIKE 'А%'` — үлгі: `%` — кез келген таңбалар саны, `_` — дәл бір таңба;
- `IS NULL` — бос мән.

**Агрегаттық функциялар** жолдар тобы бойынша есептейді: `COUNT(*)` — саны, `SUM`, `AVG` — орташа, `MIN`, `MAX`.

```sql
SELECT class, COUNT(*) AS students, AVG(score) AS avg_score
FROM students
GROUP BY class              -- әр сыныпқа бір топ
HAVING AVG(score) > 70      -- топтарға арналған шарт (WHERE — жолдарға)
ORDER BY avg_score DESC;
```

Сұрау бөліктерінің реті қатаң осындай: `SELECT → FROM → WHERE → GROUP BY → HAVING → ORDER BY`.

## Кестелерді біріктіру: JOIN
```sql
SELECT s.name, g.subject, g.score
FROM students AS s
JOIN grades AS g ON g.student_id = s.id
WHERE g.subject = 'Информатика';
```

`JOIN … ON` кілті сәйкес келетін екі кестенің жолдарын қосады: `grades.student_id` сыртқы кілтін `students.id` бастапқы кілтімен. `INNER JOIN` (жай `JOIN`) тек сәйкестігі бар жұптарды қалдырады. `LEFT JOIN` жұбы болмаса да, сол жақ кестенің барлық жолдарын қалдырады.

## Мысал: нәтижелер бойынша аналитика
`results(student, topic, textbook, score)` кестесі — Өлшем платформасындағы сияқты. Ең әлсіздерінен бастап тақырыптар бойынша орташа балл:

```sql
SELECT topic, ROUND(AVG(score), 1) AS avg_score,
       SUM(CASE WHEN score < 40 THEN 1 ELSE 0 END) AS failed
FROM results
GROUP BY topic
ORDER BY avg_score;
```

## Веб-беттің дерекқормен байланысы
Динамикалық сайтта бет деректерді өзі сақтамайды. Браузер серверге сұрау жібереді, серверлік бағдарлама (PHP, Python және басқа тілдерде) дерекқорға SQL-сұрау орындайды және жауаптан HTML-бет жинайды. Электрондық күнделік, интернет-дүкен, сайт бойынша іздеу осылай жұмыс істейді. Деректерді пайдаланушы HTML-форма (`<form>`, `<input>`, `<button>`) арқылы енгізеді, ал сервер оларды `INSERT` командасымен базаға жазады.

> Формадағы деректерді SQL-сұрауға жолдарды жай біріктіру арқылы қоюға болмайды: зиянкес SQL-кодтың бір бөлігін енгізуі мүмкін (**SQL-инъекция** шабуылы). Параметрленген сұрауларды пайдаланады.

@terms
- Деректер сұлбасы :: базаның кестелері мен олардың арасындағы байланыстардың бейнесі
- Форма :: жазбаларды ыңғайлы енгізуге және қарауға арналған ДҚБЖ объектісі
- Сұрау :: деректерді іріктеу немесе өзгерту үшін базаға жүгіну
- Есеп :: басып шығаруға безендірілген іріктеу нәтижесі
- SQL :: реляциялық дерекқорларға құрылымдық сұраулар тілі
- SELECT :: деректерді іріктеу командасы
- WHERE :: жолдарды іріктеу шарты
- GROUP BY :: агрегаттық функциялар үшін жолдарды топтау
- JOIN :: екі кестенің жолдарын кілт бойынша біріктіру
- SQL-инъекция :: форма деректеріне SQL-кодты енгізу арқылы шабуыл

@added
- Конструктор режимін және бір кестелі мен көп кестелі базаны құруды Алматыкітап қадам бойынша көрсетеді.
- Агрегаттық функциялар мен GROUP BY-ды негізінен Арман-ПВ, LIKE үлгілерін, деректерді өзгерту командалары мен JOIN-ды Атамұра талдайды.
- HAVING, LEFT JOIN, IS NULL және сұрау бөліктерінің қатаң реті бірде-бір оқулықта сипатталмаған. Олар SQL-дің стандартты бөліктері, ал SQL-сұраулар — ҰБТ 10 тақырыбы болғандықтан қосылды.
- SQL-инъекциялар туралы ескерту және тарауды Өлшем платформасымен байланыстыратын тестілеу нәтижелерін талдауға арналған сұрау мысалы қосылды.
