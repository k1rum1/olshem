## Сұрыптау
**Сұрыптау** — элементтерді өсу немесе кему ретімен реттеу. Сұрыпталған деректерді іздеу және талдау оңай.

### Көпіршікті (алмастыру арқылы) сұрыптау
Көрші элементтерді салыстырып, дұрыс тұрмаса, орындарын ауыстырамыз. Бір өтуде ең үлкен элемент соңына «қалқып шығады».

```python
def bubble(a):
    n = len(a)
    for i in range(n - 1):
        for j in range(n - 1 - i):
            if a[j] > a[j + 1]:
                a[j], a[j + 1] = a[j + 1], a[j]
    return a
```

`[5, 1, 4, 2]` үшін мысал: бірінші өту → `[1, 4, 2, 5]`, екінші → `[1, 2, 4, 5]`.

### Таңдау арқылы сұрыптау
Сұрыпталмаған бөліктен минимумды тауып, оны бірінші бос орынға қоямыз.

```python
def selection(a):
    for i in range(len(a) - 1):
        m = i
        for j in range(i + 1, len(a)):
            if a[j] < a[m]:
                m = j
        a[i], a[m] = a[m], a[i]
    return a
```

### Кірістіру арқылы сұрыптау
Келесі элементті алып, оны қолдағы карталар сияқты сұрыпталғандардың арасындағы өз орнына кірістіреміз. Дерлік сұрыпталған деректерде жылдам жұмыс істейді.

```python
def insertion(a):
    for i in range(1, len(a)):
        x, j = a[i], i - 1
        while j >= 0 and a[j] > x:
            a[j + 1] = a[j]
            j -= 1
        a[j + 1] = x
    return a
```

### Жылдам сұрыптау (Хоар)
Тірек элементті таңдап, массивті «тіректен кіші» және «тіректен үлкен» бөліктерге бөлеміз және екі бөлікті рекурсивті түрде сұрыптаймыз.

```python
def quick(a):
    if len(a) <= 1:
        return a
    p = a[len(a) // 2]
    return quick([x for x in a if x < p]) + [x for x in a if x == p] + quick([x for x in a if x > p])
```

### Салыстыру
| Алгоритм | Ең нашар жағдайдағы салыстырулар | Қашан жақсы |
|---|---|---|
| Көпіршікті | ≈ n²/2 | оқу үшін, қарапайым |
| Таңдау арқылы | ≈ n²/2, бірақ алмастыру аз | алмастыру «қымбат» болғанда |
| Кірістіру арқылы | ≈ n²/2, дерлік сұрыпталғанда ≈ n | шағын және дерлік реттелген деректер |
| Жылдам | орта есеппен ≈ n·log₂n | үлкен массивтер |

**O(n²)** жазбасы уақыттың элементтер санының квадратына пропорционал өсетінін білдіреді: n = 1000 болғанда — шамамен миллион салыстыру. **O(n log n)** — шамамен 10 000.

Python-да дайын функциялар бар: `sorted(a)` жаңа сұрыпталған тізім қайтарады, `a.sort()` тізімнің өзін сұрыптайды. Параметрлер: `reverse=True` — кему ретімен, `key=len` — ұзындығы бойынша сұрыптау.

## Іздеу
**Сызықтық іздеу** элементтерді кезекпен тексереді: n салыстыруға дейін.

**Екілік іздеу** тек **сұрыпталған** массивте жұмыс істейді. Ортаңғы элементке қараймыз: ізделетін одан кіші болса — сол жақ жартысынан, үлкен болса — оң жақ жартысынан іздейміз. Әр қадам іздеу аймағын екіге бөледі, сондықтан ⌈log₂(n+1)⌉ салыстырудан аспайды: 1000 элемент үшін — 10.

```python
def binary_search(a, x):
    lo, hi = 0, len(a) - 1
    while lo <= hi:
        mid = (lo + hi) // 2
        if a[mid] == x:
            return mid
        if a[mid] < x:
            lo = mid + 1
        else:
            hi = mid - 1
    return -1
```

## Графтар
**Граф** — **төбелер** (түйіндер) мен **қабырғалар** (олардың арасындағы байланыстар) жиыны. Графпен жол картасын, компьютерлік желіні, әлеуметтік желідегі достарды, оқу бағдарламасындағы тақырыптардың тәуелділігін сипаттауға болады.

- **Бағдарланбаған** граф — қабырғалардың бағыты жоқ (екі жаққа жүретін жол).
- **Бағдарланған** граф (орграф) — қабырғалар-нұсқамалар, оларды **доғалар** деп атайды (әлеуметтік желідегі жазылу, бір бағытты көше).
- **Салмақталған** граф — қабырғаларда сандар бар: қашықтық, уақыт, құн.
- **Төбенің дәрежесі** — одан неше қабырға шығады.
- **Жол** — қабырғалармен байланысқан төбелер тізбегі. **Цикл** — бастапқы төбеге қайтып оралатын жол.
- **Ағаш** — циклсіз байланысқан граф. n төбесі бар ағашта дәл n − 1 қабырға бар.

**Графты бағдарламада қалай сақтау керек:**
- **Іргелестік матрицасы** — n × n кесте: i жолы мен j бағанының қиылысында i–j қабырғасы болса, 1 (немесе салмақ) тұрады. Бағдарланбаған графтың матрицасы симметриялы.
- **Іргелестік тізімі** — әр төбе үшін көршілер тізімі: `{'A': ['B', 'C'], 'B': ['A'], ...}`.

|   | A | B | C | D |
|---|---|---|---|---|
| A | 0 | 4 | 1 | 0 |
| B | 4 | 0 | 2 | 5 |
| C | 1 | 2 | 0 | 8 |
| D | 0 | 5 | 8 | 0 |

## Графтардағы алгоритмдер
**Енінен аралау (BFS)** — алдымен бастапқы төбенің барлық көршілеріне барамыз, содан кейін көршілердің көршілеріне. Кезекті пайдаланады және қабырғалар саны ең аз жолды табады.

**Тереңінен аралау (DFS)** — бір тармақпен мүмкіндігінше алға жүреміз, содан кейін қайтамыз. Стекті немесе рекурсияны пайдаланады.

```python
from collections import deque
def bfs(graph, start):
    seen, order, q = {start}, [], deque([start])
    while q:
        v = q.popleft()
        order.append(v)
        for u in graph[v]:
            if u not in seen:
                seen.add(u)
                q.append(u)
    return order
```

**Салмақталған графтағы ең қысқа жол — Дейкстра алгоритмі:**
1. Бастауға дейінгі қашықтық 0, қалғандарына ∞.
2. Ең кіші қашықтығы бар барылмаған төбені алып, оны барылған деп белгілейміз.
3. Оның әр көршісі үшін қашықтықты жақсартуға тырысамыз: `d[көрші] = min(d[көрші], d[v] + салмақ)`.
4. Барылмаған төбелер болғанша қайталаймыз.

Жоғарыдағы кесте бойынша A → D ең қысқа жолы: A → C → B → D = 1 + 2 + 5 = **8** (C арқылы тікелей емес: 1 + 8 = 9).

> Графтар теориясы Эйлердің Кёнигсбергтің жеті көпірі туралы есебінен басталды (1736): барлық көпірден бір реттен өту мүмкін емес, себебі төрт «төбенің» бәрінің дәрежесі тақ.
