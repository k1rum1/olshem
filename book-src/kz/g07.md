## Жол — таңбалар тізбегі
**Жол** (`str`) — тырнақшадағы таңбалардың реттелген тізбегі: `'Тараз'` немесе `"Тараз"`.

**Индекстер** нөлден басталады. Теріс индекстер соңынан санайды:

```python
s = "ИНФОРМАТИКА"
#    0123456789...
s[0]     # 'И'
s[3]     # 'О'
s[-1]    # 'А' — соңғы таңба
len(s)   # 11
```

**Қима** `s[a:b:c]` — a индексінен b индексіне **дейінгі** (b кірмейді) c қадамымен алынған таңбалар:

```python
s[0:4]   # 'ИНФО'
s[4:]    # 'РМАТИКА'
s[:-3]   # 'ИНФОРМАТ'
s[::2]   # 'ИФРАИА' — әр екінші таңба
s[::-1]  # 'АКИТАМРОФНИ' — жол керісінше
```

> Жолдар **өзгермейді**: `s[0] = 'и'` қате тудырады. Жолды «өзгерту» үшін жаңасын жасайды: `s = 'и' + s[1:]`.

**Амалдар:** `+` — біріктіру (конкатенация), `*` — қайталау (`'ab' * 3` → `'ababab'`), `in` — ішінде бар ма тексеру (`'ФОР' in s` → `True`), жолдарды салыстыру таңба кодтары бойынша жүреді.

**Таңбаларды аралау:**

```python
vowels = 0
for ch in "алгоритм":
    if ch in "аеёиоуыэюя":
        vowels += 1
print(vowels)  # 3
```

## Жол әдістері
Әдістер бастапқы жолды өзгертпейді, жаңа жол қайтарады.

| Әдіс | Не істейді | Мысал → нәтиже |
|---|---|---|
| `upper()`, `lower()` | барлық әріптер бас / кіші | `'Python'.upper()` → `'PYTHON'` |
| `capitalize()`, `title()` | бірінші әріп бас / әр сөз бас әріппен | `'тараз'.title()` → `'Тараз'` |
| `find(x)` | бірінші кездесудің индексі, жоқ болса −1 | `'банан'.find('н')` → `2` |
| `index(x)` | find сияқты, бірақ жоқ болса қате | |
| `count(x)` | неше рет кездеседі | `'банан'.count('а')` → `2` |
| `replace(a, b)` | барлық a-ны b-мен ауыстыру | `'2+2'.replace('+', '*')` → `'2*2'` |
| `split(sep)` | бөлгіш бойынша тізімге бөлу (әдепкі бойынша бос орындар) | `'a b c'.split()` → `['a', 'b', 'c']` |
| `sep.join(list)` | жолдар тізімін sep арқылы біріктіру | `'-'.join(['1','2'])` → `'1-2'` |
| `strip()` | шеттеріндегі бос орындар мен тасымалдауларды алып тастау | `'  hi \n'.strip()` → `'hi'` |
| `startswith(x)`, `endswith(x)` | x-пен басталады / аяқталады | |
| `isdigit()`, `isalpha()` | тек цифрлар / тек әріптер | `'2025'.isdigit()` → `True` |

**Таңба кодтары:** `ord('A')` → `65`, `chr(66)` → `'B'`.

**Пішімдеу:** `f"Балл: {score}, пайыз: {p:.1f}%"` айнымалылардың мәндерін қояды, `:.1f` — үтірден кейін бір таңба.

**Мысал: сөйлемдегі ең ұзын сөз.**

```python
text = "Жамбыл облысы информатика олимпиадасы"
words = text.split()
longest = max(words, key=len)
print(longest, len(longest))  # информатика 11 (ұзындықтары тең болса, max біріншісін алады)
```

## Файлдар
**Файл** — дискідегі атаулы деректер аймағы. Файлдар **мәтіндік** (таңбалардан тұрады, блокнотпен ашуға болады: `.txt`, `.csv`, `.py`) және **екілік** (суреттер, бағдарламалар, мұрағаттар) болады.

Файлмен жұмыс: **ашу → оқу немесе жазу → жабу**.

```python
f = open("data.txt", "r", encoding="utf-8")
text = f.read()
f.close()
```

| Режим | Мағынасы |
|---|---|
| `"r"` | оқу (әдепкі бойынша); файл жоқ болса, қате |
| `"w"` | жазу; файл құрылады, ал ескі мазмұны **өшіріледі** |
| `"a"` | файлдың соңына қосып жазу |
| `"rb"`, `"wb"` | екілік файлдарды оқу және жазу |

**Оқу тәсілдері:**
- `f.read()` — бүкіл файл бір жол ретінде;
- `f.readline()` — келесі бір жол;
- `f.readlines()` — барлық жолдардың тізімі;
- `for line in f:` — жол бойынша аралау, жадты үнемдейді.

**Жазу:** `f.write("мәтін\n")` — жолды жазады. Санды алдымен жолға айналдырады: `f.write(str(x))`.

**`with`** арқылы жұмыс істеген ыңғайлы: файл қате болса да, өзі жабылады.

```python
with open("scores.txt", encoding="utf-8") as f:
    nums = [int(line) for line in f]
with open("result.txt", "w", encoding="utf-8") as out:
    out.write(f"Орташа: {sum(nums) / len(nums):.1f}\n")
```

> `encoding="utf-8"` көрсетіңіз, әйтпесе орыс және қазақ әріптері дұрыс оқылмауы мүмкін («Кодтау» тарауын қараңыз).

**Файлға дейінгі жол** **салыстырмалы** (`data/scores.txt` — бағдарлама қалтасынан) және **абсолютті** (`C:\Users\Student\scores.txt`) болады.

@terms
- Жол :: таңбалардың өзгермейтін тізбегі
- Индекс :: таңбаның жолдағы 0-ден басталатын нөмірі
- Қима :: s[a:b:c] жолының бөлігі, мұнда b кірмейді
- Конкатенация :: + амалымен жолдарды біріктіру
- Жол әдісі :: нүкте арқылы шақырылатын функция: s.upper()
- Мәтіндік файл :: мәтін ретінде оқылатын таңбалардан тұратын файл
- Ашу режимі :: файлмен жұмыс тәсілі: r, w, a
- with :: файлды автоматты түрде жабатын құрылым

@added
- Қималарды, split пен join-ды, ord пен chr-ды, циклде таңбаларды аралауды және with құрылымын тек Атамұра талдайды.
- count әдісін және isdigit пен isalpha әдістерінің толық кестесін тек Алматыкітап береді.
- Арман-ПВ конкатенацияны және мәтіндік пен екілік файлдардың айырмасын бәрінен толық түсіндіреді, бірақ жол әдістерін дерлік көрсетпейді.
- Жолдардың өзгермейтіндігі, теріс индекстер мен [::-1] қимасы, ашу режимдерінің кестесі, ашқан кездегі utf-8 кодировкасы және абсолютті мен салыстырмалы жол алғаш рет бірге жиналды. Жеке-жеке олар ең көбі бір оқулықта бар.
