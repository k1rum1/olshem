## CSS дегеніміз не
**CSS** (Cascading Style Sheets, каскадты стильдер кестелері) беттің сыртқы түріне жауап береді: қаріптер, түстер, шегіністер, блоктардың орналасуы. HTML мазмұнды, CSS безендіруді сипаттайды. Тек стильді өзгерту арқылы бір мазмұнды әртүрлі көрсетуге болады.

**CSS ережесі** селектор мен жариялаулар блогынан тұрады:

```css
h1 {
  color: #1F4FC1;        /* қасиет: мән; */
  font-size: 32px;
}
```

## Стильдерді қосудың үш тәсілі
| Тәсіл | Қалай жазылады | Қашан қолданылады |
|---|---|---|
| Кірістірілген (inline) | `<p style="color: red;">` | бір элемент үшін бір ерекшелік |
| Ішкі | `<head>` ішінде `<style> p { color: red; } </style>` | бір беттің стильдері |
| Сыртқы | `<head>` ішінде `<link rel="stylesheet" href="style.css">` | бүкіл сайттың ортақ стильдер файлы — ең жақсы нұсқа |

**Каскадтау** — элементке бірнеше ереже қатысты болса, басымырағы жеңеді: кірістірілген стиль `#id` селекторынан күшті, `#id` `.класс`-тан күшті, ал класс тег селекторынан күшті. Басымдық тең болса, кейін жазылған ереже жеңеді. Көптеген қасиеттер (түс, қаріп) ішкі элементтерге **мұраланады**.

## Селекторлар
| Селектор | Мысал | Нені таңдайды |
|---|---|---|
| Тег | `p { }` | барлық абзацтар |
| Класс | `.note { }` + `<p class="note">` | осы класы бар барлық элементтер (көп болуы мүмкін) |
| Идентификатор | `#menu { }` + `<div id="menu">` | бірегей id-і бар бір элемент |
| Контекстік (ұрпақ) | `nav a { }` | `nav` ішіндегі сілтемелер |
| Топ | `h1, h2 { }` | h1 де, h2 де |
| Жалған класс | `a:hover { }` | тінтуір көрсеткіші астындағы сілтеме |
| Әмбебап | `* { }` | барлық элементтер |

## Негізгі қасиеттер
**Мәтін және қаріп:** `font-family: Arial, sans-serif;` · `font-size: 16px;` · `font-weight: bold;` · `font-style: italic;` · `text-align: center;` · `text-decoration: underline;` · `line-height: 1.5;` · `color: #333;`.

**Фон:** `background-color: #F0F3F8;` · `background-image: url(bg.png);`.

**Блоктық модель.** Әр элемент — қабаттардан тұратын тіктөртбұрыш: **мазмұн** (`width`, `height`) → **ішкі шегініс** `padding` → **жиектеме** `border` → **сыртқы шегініс** `margin`.

```css
.card {
  width: 300px;
  padding: 16px;              /* жиектеме ішінде */
  border: 1px solid #CCC;     /* қалыңдығы, стилі, түсі */
  margin: 20px auto;          /* сыртында; бүйірлерде auto — ортада */
}
```

**Блоктардың орналасуы:** `display: block | inline | none` (none — жасыру), `float: left` (орап өту), `display: flex` (элементтер туралаумен қатарға), `display: grid` (тор), `position: relative | absolute | fixed` (нақты орын).

**Бірліктер:** `px` — пиксельдер, `%` — ата-элементтен, `em` және `rem` — қаріп өлшемінен.

## Мультимедиа
```html
<audio src="kui.mp3" controls></audio>
<video src="lesson.mp4" width="640" controls poster="cover.jpg">
  Браузеріңіз бейнені қолдамайды.
</video>
```

| Атрибут | Мағынасы |
|---|---|
| `controls` | ойнату батырмаларын көрсету |
| `autoplay` | бірден бастау (браузерлер дыбыс өшірулі болса ғана рұқсат етеді — `muted`) |
| `loop` | шеңбер бойымен қайталау |
| `muted` | дыбыссыз |
| `poster` | бейне іске қосылғанға дейінгі сурет |

Пішімдер: дыбыс — MP3, OGG, WAV; бейне — MP4, WebM, OGG. YouTube бейнелері мен карталар сіздің бетіңіздің ішінде басқа бетті көрсететін `<iframe src="...">` тегімен кірістіріледі.

## JavaScript-тегі скрипттер
**JavaScript** — браузерде орындалатын және бетті интерактивті ететін бағдарламалау тілі: басуларға жауап береді, формаларды тексереді, мазмұнды бетті қайта жүктемей өзгертеді.

Кодты `<script>` тегінде жазады немесе файлмен қосады: `<script src="app.js"></script>`.

```html
<input id="age" type="number" placeholder="Жасы">
<button onclick="check()">Тексеру</button>
<p id="out"></p>
<script>
  function check() {
    let age = Number(document.getElementById("age").value);
    let text = age >= 18 ? "Дауыс беруге болады" : "Әлі ерте";
    document.getElementById("out").textContent = text;
  }
</script>
```

- `let` және `const` айнымалыларды, `function` — функцияны жариялайды;
- **оқиғалар**: `onclick` (басу), `onmouseover` (көрсеткішті апару), `onchange` (өрістің өзгеруі), `onload` (бет жүктелді);
- `alert("мәтін")` хабарламасы бар терезені, `prompt()` — енгізу терезесін көрсетеді, `document.write()` бетке жазады (ескірген тәсіл);
- `document.getElementById("id")` элементті табады, оның мәтінін немесе стилін өзгерту үшін.

@terms
- CSS :: веб-беттердің сыртқы түрін сипаттау тілі
- Селектор :: стильді қай элементтерге қолдану керектігін көрсететін ереже бөлігі
- Класс :: элементтер тобына ортақ class атрибуты; CSS-те — .атауы
- Идентификатор :: элементтің бірегей id атрибуты; CSS-те — #атауы
- Каскадтау :: элементке бірнеше ереже қатысты болғанда стильді таңдау ережелері
- Блоктық модель :: элементтің мазмұны, padding, border және margin
- JavaScript :: браузерде орындалатын бағдарламалау тілі
- Оқиға :: скрипт жауап беретін пайдаланушының немесе браузердің әрекеті

@added
- Ережелер синтаксисі, контекстік селекторлар және onclick оқиғалары Алматыкітапта ең толық. Қаріп қасиеттерін, блоктық модельді, орналастыруды және flex пен grid-тегі беттеуді тек Атамұра талдайды.
- audio тегін Арман-ПВ мен Атамұра толық сипаттайды.
- Оқулықтардың ешқайсысы стильдер басымдығын түсіндірмейді. Атамұра оны бір рет, :hover жалған класын Алматыкітап бір рет атайды. Басымдықтар мен мұралану кестесі қосылды.
- iframe тегі бірде-бір оқулықта жоқ. Ол muted және poster атрибуттарымен және браузерлердегі autoplay шектеуімен бірге қосылды.
- JavaScript мысалы заманауи синтаксиске қайта жазылды: var және document.write орнына let және textContent.
